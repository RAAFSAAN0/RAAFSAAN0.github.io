This project presents a real-time face detection and recognition system developed using a custom convolutional neural network. The model was trained on more than 4,000 facial images and integrated with OpenCV for webcam-based inference and real-time recognition.

# Overview

This project focuses on developing a real-time face detection and recognition system using deep learning and computer vision techniques. A custom convolutional neural network was trained to recognize faces from a dataset containing more than 4,000 facial images.

# Model

A custom convolutional neural network was designed and trained using TensorFlow to perform face recognition. The training process involved preprocessing facial images and learning visual features that could be used to distinguish between different identities.

# Real-Time Recognition

OpenCV was used to implement webcam-based inference. The system captures frames from the webcam, processes the detected faces, and performs recognition using the trained CNN model.

Frame processing was optimized to support real-time operation while maintaining reliable recognition performance.
